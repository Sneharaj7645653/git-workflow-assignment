1. git init -b main
   Initializes a new local Git repository and sets the default branch name to 'main'.

2. git status
   Displays the current state of the working directory and staging area, showing tracked, untracked, and staged files.

3. git add <filename>
   Moves modified or newly created files from the working directory into the staging area in preparation for a commit.

4. git commit -m "<message>"
   Records a permanent snapshot of the staged changes in the repository history with a descriptive commit message.

5. git checkout -b feature
   Creates a new branch named 'feature' and immediately switches the working directory to that branch.

6. git branch
   Lists all local branches in the repository and highlights the currently active branch.

7. git checkout main
   Switches the active branch back to the 'main' branch.

8. git merge --no-ff feature -m "<message>"
   Integrates changes from the 'feature' branch into 'main' while creating an explicit merge commit to preserve branch history.

9. git log --oneline --graph --all --decorate
   Displays a compact visual graph of all commits, branches, and merge points across the repository history.

10. git revert HEAD --no-edit
    Undoes the changes introduced by the most recent commit by creating a new inverse commit, safely preserving history.

11. git remote add origin <repository-url>
    Connects the local Git repository to a remote GitHub repository under the alias 'origin'.

12. git push -u origin main
    Uploads all local commits on the 'main' branch to the remote GitHub repository and sets upstream tracking.
